How it's built

Every outfit, block and texture is generated from a single definition. Each release then passes six layers of testing — from a rendered-image check that poses the model against approved pictures, through a live Bedrock Dedicated Server run, to a simulated player that tames a cat by hand, saddles it and rides it before anything ships.

From one definition, through automated testing, to release.
